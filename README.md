## English Summary

**EL6751 CAN over EtherCAT using SOEM**

This project demonstrates CAN bus communication via a Beckhoff EL6751 CAN master terminal connected to an EK1100 EtherCAT coupler, running on a Linux real-time system using the [Simple Open EtherCAT Master (SOEM)](https://github.com/OpenEtherCATsociety/SOEM) library.

### Entry point

`SOEM/test/linux/simple_test/main.c`

### Main features

- Reads per-slave configuration from CSV files (`SOEM/test/linux/simple_test/csv/read<N>.csv`)
- Configures EL6751 PDO mappings via CoE (CAN over EtherCAT) SDO writes using register groups `0x8000`, `0x8006`, `0x8008`, `0x8003`, `0xF800`, `0x1C12`, and `0x1C13`
- Sends and receives CAN messages cyclically through EtherCAT process data (PDO)
- Forwards received CAN data over UDP for external monitoring (e.g. MATLAB/Simulink)

### CSV configuration files

CSV files encode the EL6751 register settings and PDO layout. They can be generated by:
- TwinCAT (export from the EL6751 startup list)
- The MATLAB app provided in the `Setting/` directory (`generate_can_setting.mlappinstall`)

### Build

```bash
cd SOEM
export PRJ_ROOT=$(pwd)
cd test/linux/simple_test
make
```

### Usage

```bash
sudo ./multican <ifname>
# e.g. sudo ./multican eno1
```

`ifname` is the name of the Ethernet interface connected to the EtherCAT network.
